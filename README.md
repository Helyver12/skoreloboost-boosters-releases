# SkoreloBoost Boosters — releases

Esse repositório guarda só os instaladores (.exe) publicados do app de Windows usado pelos
boosters da SkoreloBoost (painel, bandeja do sistema, login automático de conta). O
código-fonte é privado e fica em outro repositório.
